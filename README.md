# موقع مناهل طيبة العقاري

موقع عربي متجاوب مع عرض العقارات، البحث والتصفية، استقبال طلبات العملاء، وتسجيل دخول مسؤول لإدارة العروض والطلبات. الشعار مضمّن في `assets/logo.jpg`.

## تجربة التصميم

افتح `index.html` في متصفح حديث أو شغّل خادمًا محليًا داخل المجلد: `python -m http.server 8000` ثم افتح `http://localhost:8000`. تظهر **3 عروض توضيحية فقط** في وضع المعاينة؛ لا تحفظ الطلبات ولا تعمل لوحة الإدارة قبل ربط Supabase. هذه العروض ليست عروضًا حية ولا تؤكد توفر العقارات.

## تفعيل الوظائف الحقيقية مجانًا ضمن حدود الخطط

1. أنشئ حسابًا ومشروعًا مجانيًا على https://supabase.com.
2. افتح SQL Editor في Supabase ونفّذ محتوى `database.sql` مرة واحدة على مشروع جديد. إن أعدت التنفيذ قد تظهر أخطاء تكرار سياسات الوصول.
3. من Authentication > Users أنشئ حساب المسؤول ببريدك وكلمة مرور قوية (أو استخدم دعوة بريدية حسب واجهة Supabase). عطّل التسجيل العام من إعدادات Auth إذا كنت لا تحتاج تسجيل مستخدمين.
4. انسخ **UUID** الخاص بحساب المسؤول، ثم نفّذ في SQL Editor: `insert into public.admin_users(user_id) values ('YOUR-REAL-UUID');` واستبدل القيمة بمعرف المستخدم الحقيقي. لا تشارك المعرف أو بيانات الدخول مع العملاء.
5. من Project Settings > API أو Connect انسخ **Project URL** ومفتاح `anon` / `publishable` العام فقط، وضعهما في `config.js`. **ممنوع** استخدام مفتاح `service_role` أو secret داخل الملفات المنشورة.
6. ارفع جميع الملفات والمجلد `assets` إلى مستودع GitHub جديد، واجعل `index.html` في الجذر.
7. من Settings > Pages اختر Deploy from a branch ثم `main` و`/(root)` واحفظ. انتظر نشر الموقع على رابط `https://USERNAME.github.io/REPOSITORY/`.
8. افتح الرابط، اضغط لوحة الإدارة وسجّل الدخول، ثم أضف العروض والصور. يمكن استقبال طلبات الزوار وعرضها في لوحة الإدارة.

## تنبيهات مهمة

- النشر والاستضافة وقاعدة البيانات ضمن خطط مجانية ذات حصص وقيود قابلة للتغيير. ليس ضمانًا لموقع مجاني بلا حدود إلى الأبد.
- رابط GitHub Pages عام؛ **لا تضع كلمات المرور أو مفاتيح سرية** في المستودع. بيانات الطلبات لا تُقرأ من الزوار بفضل سياسات RLS في قاعدة البيانات.
- نموذج الطلبات مفتوح للجمهور وقد يحتاج حماية من السبام قبل الإطلاق الفعلي (مثل CAPTCHA / rate limiting عبر خدمة خلفية). يوصى بتفعيل وسائل مكافحة الإساءة ومراجعة إشعار الخصوصية ومتطلبات حماية البيانات الشخصية في السعودية قبل استقبال بيانات حقيقية.
- لا تُنشر عقارات حقيقية إلا بعد التحقق من توفرها وصحة البيانات والتراخيص المطلوبة للإعلانات العقارية.
- رفع صورة جديدة عند تعديل العرض لا يحذف الصورة القديمة تلقائيًا من التخزين؛ راجع التخزين دوريًا.
- لا يتضمن المشروع تنبيهات واتساب آلية أو إدارة مستخدمين متعددين أو نسخًا احتياطية مخصصة.
- صور العقارات المعروضة في وضع المعاينة رمزية فقط، والشعار رسمي مقدم من صاحب المشروع.
